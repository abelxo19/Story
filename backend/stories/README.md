# Story sources

Markdown in this folder is the source of truth for the NestJS API.

| File | Text | Rights |
| --- | --- | --- |
| `hansel-and-gretel.md` | Brothers Grimm, *Hansel and Grethel* | Public domain. From [Grimm's Fairy Stories](https://www.gutenberg.org/ebooks/11027) (Project Gutenberg #11027, 1922 English edition). |
| `snow-white.md` | Brothers Grimm, *Little Snow White* | Public domain. Same Gutenberg collection. |
| `the-hobbit.md` | Original short retelling | Not Tolkien's novel. Written for this portfolio so the app can be shared without copying a copyrighted book. |
| `harry-potter.md` | Original short retelling | Not Rowling's novels. Written for this portfolio so the app can be shared without copying a copyrighted book. |

To restore the Grimm files from Gutenberg, run:

```bash
python scripts/extract-grimm.py
```
